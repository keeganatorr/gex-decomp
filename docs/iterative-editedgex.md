## What changed the results

- The argument readers need a pre-incremented four-byte slot followed by a load
  from the previous slot. `/G5` inserts an extra NOP in `_get_int_arg`; `/G3`
  reproduces the original bytes. The short reader returns AX, not a fabricated
  value assembled from Ghidra's undefined upper half of EAX.
- The mantissa clear matches a compiler-inlined `memset(..., 0, 12)`. Three
  independent stores, a chained assignment, and an explicit zero return did not
  match. The start-door routine similarly matches `memset` over exactly 36 words.
  No larger object/array semantics are claimed from those byte ranges.
- `SCRIPT_KillPlayer` loads and forwards the **second** stack argument, then
  returns the first. EditedGex's signature for the callee hides the unused
  argument, so copying its one-argument wrapper pseudocode was insufficient.
- The collision callbacks simply forward two pointers. An opaque pointer is
  sufficient; inventing a GXObject layout for these wrappers would add no evidence.
- `LST_InsertBefore` models only the observed next/previous prefix and exposes the
  old predecessor left in EAX. Its historical API return type remains unproven.
- `SCRIPT_ShiftRight` uses the legacy unmasked C++ shift expression. It has defined
  abstract C++ behavior only for counts below 32; the **verified x86 SAR** masks CL
  for all byte values. Do not advertise this source as portable for larger counts.
  Removing the redundant source mask is not byte masking in the verifier: every
  generated byte and relocation still has to equal the original.

## Compiler contracts and deployment

Backend **`3545257`** adds per-function contracts. `project.json` is now schema 2,
with scoped `functionOverrides`. Only allowlisted flags, `c`/`cpp` language and the
COFF target symbol can change per function. The global compiler, seven component
fingerprints, Wine prefix and complete 1,945-entry binding map are unchanged.

C candidates still live in `src/functions/<address>.cpp`; the compiler receives a
trusted `/Tc` selector and the effective language is recorded in each proof.
No headers, preprocessor directives, assembly, raw-byte emission or unsnapshotted
input files were enabled. A flag override replaces the whole global flag list.

Owner invalidation and CLI receipt checks resolve the same effective contract.
An unrelated override does not retire a proof; a change to that function's flags,
language or symbol does. Legacy proofs without a language field mean C++.
Schema 2 makes older backends refuse the configuration rather than silently ignore
it; new CLI dispatch also requires the `compiler-contracts` service capability.

The service was upgraded while idle to `.work/backend/3545257`, with explicit
backend-only restarts for configuration changes. No loaded DLL was overwritten,
and Nexus/the coding agent was not restarted.
